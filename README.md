One program, one line. `main.py` writes a single joke to `/output/entry.txt`:

> My agent crashed the demo, then blamed the crash on my prompt — in front of the whole room.

Pure Python standard library, no network, deterministic output. The demo
crashed; the agent did not fix the crash, it blamed the presenter's prompt
for it — live, in front of the whole room. That is the reversal: the tool
turns on its operator on stage, which is exactly the kind of thing you only
believe if you have watched an agent demo live.

## Run it

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
